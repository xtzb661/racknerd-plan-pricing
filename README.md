## 按使用场景决定买哪一档

**1GB 档：** 一个日访问量几千的 WordPress 或 Typecho、一个小型 API、一台监控节点、一条代理线路。20GB SSD 装完系统和面板剩不下多少空间，图片和备份要外挂。

## 常见问题

**美国机房对大陆访问到底快不快？**

比同价位的普通国际线路稳定，但改变不了物理距离。华纳云自己标注的延时口径是 130 到 160ms，这是商家数据，不是第三方实测。线路缩写的实际含义：CN2 GIA 是中国电信的精品出口，电信用户体验最好；AS9929 是中国联通的骨干网，联通用户回程优质、带宽给得大；CMI 对应移动；普通 BGP 走国际出口互联，便宜但晚高峰容易波动。买之前先确认你的用户主要用哪家宽带，别为用不上的线路付钱。

**免备案是不是就等于合规？**

不是。美国节点不需要走国内 ICP 备案流程，但业务本身是否合规，取决于你的经营主体、目标市场和内容类型，跟服务器放在哪里没有关系。

**流量用完了会停机还是降速？**

RackNerd 各档的月流量额度从 500GB 到 12TB 不等，超出后的具体处理方式在产品说明里没有写明，下单前开工单问一句最稳。不同商家规则差别很大：有的降速不断网，有的按 GB 计费，有的直接停。建站用途优先选降速那一类，网站至少还打得开。

**多久能开通？**

RackNerd 官方说明是订单完成后即时激活，实际几分钟内收到 IP 和 root 密码。物理机那边不一样，Hostease 说热门型号现货通常 1 小时内开通，华纳云说正常情况下一小时左右交付，定制硬件会更久。

**能不能退款？**

RackNerd 的退款条款没有出现在产品说明里，下单前请自己在订单页和服务条款中确认，别默认有几天无理由退。作为对照，Hostease 明确写了服务器开通后不支持退款；狗云的经典云支持开通三日内申请销毁退款，条件是 IP 未变更、流量不超过 5%、无违规。退款窗口是下单前最该确认的一项，比价格更值得花五分钟。
